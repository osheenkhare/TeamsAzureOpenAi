Lab Troubleshooting Guide

A guide to troubleshoot common lab issues.

Steps to Resolve
  1. If the Azure AI Foundry setup fails, you will see a screen pre-filled with default values.
  2. Click Create and ensure the Set up recommended... toggle is OFF.

Steps to Resolve
  1. Run devtunnel again in the same white terminal window:
    devtunnel host -p 3978 --allow-anonymous
  2. Copy the new tunnel endpoint shown next to Connect via browser in the terminal.
    Note: If devtunnel stops after the app is installed in Teams, follow the steps below.
  3. Go to the Teams CLI and run:
    teams app
  4. Select App, then select Zava-Help-Desk.
  5. Select Update App > Endpoint and enter the new tunnel endpoint with /api/messages appended.
    Example: https://DOMAIN.asse.devtunnels.ms/api/messages
  6. In the CLI, select Navigate Back.
  7. Select Get app details.
  8. Select Install in Teams.
